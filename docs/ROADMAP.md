# MotionShot Product & Architecture Roadmap

This document outlines planned enhancements, architectural milestones, and feature goals for upcoming releases of MotionShot.

---

## 🎯 Short-Term Milestones (v1.2 - v1.5)

- [ ] **AI-Powered Background Segmentation Engine**:
  - Implement a `MediaPipeMotionEngine` realization using MediaPipe Selfie Segmentation for hair-thin subject extraction.
- [ ] **Custom Sequence Blend Modes**:
  - Add Opacity Decay slider and blend mode options (Uniform, Fade Out, Motion Trails).
- [ ] **Export Options**:
  - Direct export to High-FPS Animated GIF and MP4 video clip.

---

## 🚀 Long-Term Vision (v2.0+)

- [ ] **Real-Time GPU Shader Compositing**:
  - Migrate compositing pipeline to Vulkan / OpenGL ES compute shaders for 60 FPS real-time stroboscopic preview in viewfinder.
- [ ] **Multi-Subject Tracking & Selection**:
  - Interactive tap-to-select subject tracking.
